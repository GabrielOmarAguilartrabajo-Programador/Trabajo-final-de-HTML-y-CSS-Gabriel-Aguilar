Necesito que sigas estas indicaciones:

* Este es un proyecto centrado en HTML y CSS.  
* Utiliza siempre estilos css, no librerias ni frameworks  
* Estopa prohibido usar TAILWIND  
* utiliza una estructura simple en html de header, main y footer.  
* Utiliza las imágenes de la carpeta Assets  
* En HTML ordena las líneas de código  
* En CSS debe seguir estrictamente este órden  
  1 Reset y Variables: Selector universal * (margin: 0; padding: 0; box-sizing: border-box;) y pseudoclase :root con la paleta de colores y tipografías.   
  2 Estilos por sección: Reglas organizadas por bloques usando clases reutilizables.  
  3 Responsive al final: Todas las @media deben ubicarse al final del archivo   
* El CSS debe estar adaptado a responsive  
* Maquetación moderna: Uso obligatorio de Flexbox y/o CSS Grid para distribuir menús, tarjetas y galerías, combinando unidades fijas (px) y relativas (rem, %, vh, vw).   
* usa programación declarativa  
* se conviertan en un AGENT.md . dame el texto con su formato correspondiente en extensión markdown
